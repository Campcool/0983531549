# 潔淨坊清潔工作室網站

React 與 Vite 製作的潔淨坊清潔工作室第一版首頁。

## 目前範圍

- Mobile-first 首頁
- 套用潔淨坊品牌 Logo、藍綠色系、Favicon 與 OG 圖
- 實際案場照片區塊與首頁 Hero 視覺
- 需求情境、詢問流程、清潔前確認事項、服務地區、FAQ
- LINE ID `chenli0775` 與電話 `0983531549` 聯絡入口
- 基礎 SEO、Open Graph 與 JSON-LD

## 內容邊界

第一版不放未確認的價格、評論、年資、認證或人物故事。案場照片使用本次提供素材，文案不加入未確認的客戶名稱、成果數字或前後對比。

## 素材

- `public/brand/`：首頁 Logo、分頁小圖示與品牌圖標。
- `public/og-image.png`：社群分享用 OG 圖。
- `public/cases/`：已提供的實際案場清潔照片。

## 本機開發

```bash
pnpm install
pnpm dev
```

## 建置

```bash
pnpm build
```
